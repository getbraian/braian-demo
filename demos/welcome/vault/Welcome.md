# Welcome to BrAIan

Start here: open a note, write a thought, follow a link.

This is your own trial vault. Its notes are ordinary Markdown files in `.braian-demo/vault` inside this Codespace.

## Try the basics

- Open [[Notes/A first note]] and add something to its checklist.
- Browse the Website folder: it contains HTML and CSS, not application source.
- Press **⌘K** on Mac or **Ctrl+K** elsewhere for Spotlight. Search for a note, command or Settings.

## Grow when you are ready

Only Files is enabled at first. In Settings, turn on the tools you want for this vault: Spaces, Topology, Calendars, Boards, Chat and more. Connect your own AI provider only if you want AI features.

This trial runs on your GitHub Codespace, not your computer. Your GitHub account's Codespaces quota or billing applies. Stop the Codespace when you are done, and download any notes you want to keep before deleting it.
